# Release Notes: OFORI Power Tool v1.1.0

## Summary

Version 1.1.0 upgrades OFORI Power Tool from a single-page calculator into a modular engineering screening application. The release adds harmonic distortion analysis, clearer technical distinctions, a synchronized printable report, and standardized publication materials.

## Highlights

- Harmonics screening is now included alongside power factor correction.
- The user interface distinguishes displacement PF from true PF.
- Capacitor correction results are presented separately from harmonic mitigation guidance.
- Files are organized into maintainable modules under `assets/css` and `assets/js`.
- Publication write-ups are included for common research and software dissemination platforms.

## Limitations

The software provides engineering screening estimates. Final designs should be checked with measured site data, current utility requirements, and applicable electrical standards.
