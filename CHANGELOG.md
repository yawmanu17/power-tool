# Changelog

## 1.1.0 - 2026-07-03

- Reorganized the application into professional static modules for styles, calculations, storage, charts, reporting, and UI control.
- Added harmonics screening with voltage THD, current THD, dominant harmonic order, nonlinear load share, distortion factor, harmonic apparent power, transformer K-factor estimate, and risk guidance.
- Added explicit distinctions between displacement power factor, true power factor, reactive power, and harmonic distortion.
- Rebuilt the printable report page so it reads saved calculator state and presents synchronized results.
- Added platform-ready release and publication write-ups for GitHub, Zenodo, OSF, Figshare, and scholarly publication use.
