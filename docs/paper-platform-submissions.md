### Description

OFORI Power Tool is a static browser-based engineering screening application for preliminary load analysis, power factor correction, harmonic distortion review, economics, report generation, and standards-aware review. It supports single-phase and three-phase systems, LV/MV voltage selection, 50/60 Hz operation, motor horsepower input, kW + PF, kVA + PF, kW + kVAr, current + PF, efficiency, demand factor, utility rates, voltage THD, current THD, dominant harmonic order, nonlinear load share, and detuned capacitor bank indication. The application calculates real power, reactive power, apparent power, displacement power factor, true power factor, line current, correction kVAr, capacitance, monthly cost impact, harmonic apparent power, transformer K-factor exposure, and standards-aware review prompts. The accompanying manuscript follows an IEEE-style structure and includes numbered equations for the implemented calculation methods.

## arXiv / SSRN-Style Abstract

Power factor correction is commonly treated as a capacitor-sizing calculation, but modern facilities also require attention to nonlinear loads, harmonics, voltage class, equipment nameplate data, cost impacts, and installation review. This paper presents OFORI Power Tool, a browser-based engineering screening application for load analysis, power factor correction, harmonics screening, economics, reporting, and standards-aware review. The application accepts practical field inputs including motor horsepower, kW, kVA, kVAr, current, power factor, voltage, efficiency, demand factor, operating schedule, utility rates, voltage THD, current THD, dominant harmonic order, nonlinear load share, and detuned capacitor bank indication. It calculates power quantities, correction kVAr, capacitance, displacement PF, true PF, harmonic apparent power, transformer K-factor exposure, and cost estimates. The paper follows an IEEE-style structure with numbered equations and a validation case. The contribution is a transparent static web application that supports early-stage engineering screening while distinguishing software outputs from final standards compliance and detailed professional design.
