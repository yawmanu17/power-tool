## Description

OFORI Power Tool is a modular static web application for evaluating electrical loads, power factor correction needs, energy and reactive cost impacts, and harmonic distortion risk. The tool reports real power, reactive power, apparent power, displacement power factor, true power factor, capacitor bank requirements, harmonic apparent power, and transformer K-factor screening estimates.
