## Description

OFORI Power Tool is a modular static web application for evaluating electrical loads, power factor correction needs, energy and reactive cost impacts, harmonic distortion risk, and standards-aware review prompts. The tool reports real power, reactive power, apparent power, displacement power factor, true power factor, capacitor bank requirements, harmonic apparent power, transformer K-factor screening estimates, charts, tables, JSON export, and printable reports.

The upload may include the accompanying IEEE-style software paper package, which documents the calculation basis, numbered equations, standards-aware review framing, validation example, claim boundaries, and limitations for publication use.
